FACIAL EMOTION RECOGNITION — STREAMLIT

Files in this starter:
- app.py
- requirements.txt

IMPORTANT:
Add your own trained model file named exactly:
best_fer_model.h5

Your GitHub repository should contain all three files:
app.py
requirements.txt
best_fer_model.h5

Deployment:
1. Create a GitHub repository.
2. Upload all three files to the repository's main/root folder.
3. Go to https://share.streamlit.io/
4. Sign in with GitHub and choose Create app.
5. Select your repository, branch (usually main), and main file path app.py.
6. Deploy.

Do not upload kaggle.json or any API credentials.
